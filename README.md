# Skills

Agent skills by Camgineer. Each folder under `skills/` is one skill. Copy the folders you want into your agent's skills folder, for example `.agents/skills/`.

| Skill | What it does |
|---|---|
| [openprojects](skills/openprojects/SKILL.md) | Turns a chat into a project coordinator. It acknowledges each ask, runs each piece of work in its own chat on its own branch, keeps shared project memory, and drives pull requests to green. You invoke it yourself. |
